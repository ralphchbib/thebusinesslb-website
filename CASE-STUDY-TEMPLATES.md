# Case Study Templates

5 complete frameworks, placeholders only. **No real client information is used anywhere in this document.**

**How to use these**: each framework has 11 sections — more than the Payload `CaseStudies` collection has fields for. That's deliberate: the extra sections (Client Background, Objectives, Implementation) are *planning* structure to help whoever's writing think it through properly. When entering the case study into Payload, condense as shown in the mapping note under each framework — `challenge` absorbs Client Background + Challenge + Objectives, `solution` absorbs Solution + Implementation.
