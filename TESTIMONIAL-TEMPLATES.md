# Testimonial Templates

10 placeholder templates, spread across industries, business sizes, and services, matching the exact fields in `payload/collections/Testimonials.ts`. **No real clients, companies, or quotes are used anywhere in this document** — every bracketed value is a placeholder to be replaced with real, client-approved content before publishing (see `CONTENT-ACTIVATION-PLAN.md`'s approval workflow).

Field reference for each template: `clientName`, `companyName`, `position`, `industry` (must be one of the 11 existing values), `quote`, `rating` (1–5), `featured` (yes/no recommendation only — actual value is an editor decision).
